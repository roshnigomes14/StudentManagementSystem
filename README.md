Student Management System

A web-based Student Management System developed using Python and Django.


Technologies Used

- Python
- Django
- HTML and CSS

Features

- Add, view, update, and delete student records
- Search student details
- Manage student information


How to Run

1. Clone the repository from GitHub.
2. Create and activate a virtual environment.
3. Install the required dependencies using `pip install -r requirements.txt`. If there is no `requirements.txt` file, run `pip install django Pillow`.
4. Navigate to the folder containing `manage.py`.
5. Run database migrations using `python manage.py migrate`.
6. Start the development server using `python manage.py runserver`.
7. Open `http://127.0.0.1:8000/` in your browser.
